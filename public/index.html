    When a student hands in feedback

    1. 1The browser sends the course, grade and comment to the server.
    2. 2The server asks OpenAI for the tone, topics, highlights and a suggestion.
    3. 3Offensive comments are sent back. All others are saved with the AI note.
    4. 4The professor opens the report cards and asks the AI for a briefing.
