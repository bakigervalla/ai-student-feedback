Request flow

What happens when a student clicks “Submit”

  1. 1The browser sends the rating and comment to the Node.js server.
  2. 2The server asks OpenAI for the sentiment, topics, a tone check and a summary as JSON.
  3. 3Offensive comments are rejected; the others are saved with the AI result.
  4. 4The professor dashboard shows the statistics and an AI report on request.
