What happens when a student submits

  1. 1The browser sends the rating and comment to the server.
  2. 2The server asks OpenAI to analyse the comment and return JSON.
  3. 3Offensive comments are rejected; the others are saved with the AI result.
  4. 4The dashboard shows statistics, charts and an AI summary for the professor.

Tech stack

  • Frontend: HTML, Tailwind CSS, Font Awesome, Chart.js
  • Backend: Node.js + Express
  • AI: OpenAI API (gpt-4o-mini)
  • Cloud: Render (PaaS), deployed from GitHub
  • Security: the API key is an environment variable on Render, never in the browser
